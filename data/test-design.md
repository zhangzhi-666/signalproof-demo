# SignalProof 验收集设计

本目录保存固定验收输入和人工书写的预期结果。`tests.json` 是课程要求的数学验收集；`robustness.json` 是单独的条件、定义域、能力边界与解析安全检查。测试执行器只能读取预期值进行比较，不应覆盖、反向生成或自动放宽这些预期。

## 数学验收集

| 领域 | 正确推导 | 错误推导 | 合计 |
| --- | ---: | ---: | ---: |
| 卷积 | 10 | 10 | 20 |
| 傅里叶变换 | 14 | 14 | 28 |
| 拉普拉斯变换 | 14 | 14 | 28 |
| Z 变换 | 12 | 12 | 24 |
| 合计 | 50 | 50 | 100 |

每对 `*-OK` / `*-ERR` 使用相同数学起点。正确答案以及错误位置由测试作者事先写定，没有调用被测引擎计算答案。负例是有目的的错误变异，覆盖符号、系数、变量替换、运算类型、初值与收敛域；不是统一在答案后面加常数。

`expectedFirstError` 是第一条可确认错误的相邻推导的目标行号，采用从 1 开始的编号。两行推导的错误在第 2 行。正确推导必须返回 `null`。

## 规则覆盖映射

| 执行规则 | 固定测试前缀 | 主要判定对象 |
| --- | --- | --- |
| C01–C08 | C01–C08 | 交换、结合、分配、常数、冲激恒等、冲激移位、零元、卷积微分 |
| F01–F12 | F01–F12 | 线性、时移、频移、尺度、共轭、时微分、乘 t、卷积、乘积、冲激、指数、高斯 |
| L01–L10 | L01–L10 | 线性、一阶导数、二阶导数、乘 t、复频移、因果延迟、因果卷积、积分、阶跃、指数 |
| Z01–Z10 | Z01–Z10 | 线性、移位、反转、指数加权、乘 n、卷积、共轭、冲激、右边几何序列、左边几何序列 |

补充测试 C09–C10、F13–F14、L11–L14、Z11–Z12 验证离散冲激、复合变换、多步推导与真实边界，没有把重复例题称为新规则。X/H/G 的基础变换映射可以作为 F00/L00/Z00 单独注册，不能冒充上述性质规则。

## 需要在演示中保留的检查

- **C08：卷积微分。** 卷积的导数可以落在任意一侧，不应把两种相等写法相加。负例恰好多出一份。
- **C10：首错与传播。** 负例第 2 行把 `x(t-2)` 写为 `x(t+2)`，第 3 行相对于错误前提继续正确地移位。第一错误仍是第 2 行；第 3 行可以显示“局部成立，但继承上游错误”。
- **F04：负尺度。** `x(-2*t)` 的幅度系数是 `1/2`，不是 `-1/2`。
- **F09：归一化。** 在本项目 Fourier 约定下，时域乘积对应频域卷积必须有 `1/(2*pi)`。
- **F13：复合尺度与时移。** `x(2*(t-3))` 对应 `exp(-3*I*w)*X(w/2)/2`，不能把相位写成 `exp(-6*I*w)`。
- **F14：末行错误。** 前三行都正确；第 4 行将两个同项相加误写为相减。必须返回第 4 行，不能只比较首末式后返回第 2 行。
- **L02–L03、L11–L12：初值。** 非零、零初值及初始速度必须分别处理，不能统一假设为零。
- **L13、Z09：收敛域错误。** 表达式正确但 ROC 方向错误也必须判错。
- **L14：符号等价。** 带相同 ROC 的 `1/(s+2)` 与 `(s+2)/(s+2)^2` 应可由代数化简确认。
- **Z10：左边序列。** `-2^n*u(-n-1)` 的变换是 `z/(z-2)`，ROC 为 `abs(z)<2`。序列前面的负号不是变换结果前面再加负号。
- **Z12：中间结果之后出错。** 第 2 行变换正确，第 3 行将频域乘积改成和，首错必须为第 3 行。

## 数学约定及适用条件

1. Fourier 使用 `exp(-I*w*t)` 的正变换核，逆变换系数为 `1/(2*pi)`；t、w 实数。
2. Laplace 使用从 `0-` 开始的单边变换，一阶导数规则为 `s*X(s)-x(0-)`。初值通过 `context.initial` 显式提供。因果规则通过 `context.causal` 显式提供。
3. Z 使用双边求和，n 为整数，z 为复数。几何序列的表达式与 ROC 一起比较。
4. 泛型 x/h/g 的形式变换假定存在；未指定原始 ROC 时，泛型性质不声称给出精确 ROC。指数与阶跃等已知变换对检查显式 ROC。
5. 经典规则均按其适用条件执行。符号参数缺少正性、非零或初值条件时，不得以抽样结果补齐假设。
6. 普通代数表达式的相等按双方公共定义域判断；这不等于宣称所有被约去的奇点均有函数值。变换对的 ROC 另行保留与检查。

## 边界集

`robustness.json` 共 24 条，独立于 50 正确 / 50 错误指标：

| 范围 | 测试 |
| --- | --- |
| 白名单解析、禁止导入/属性/文件操作 | R01–R05 |
| 除零、平方根的定义域 | R06–R07 |
| 正性、尺度非零与显式条件 | R08–R11 |
| 缺少 ROC 的不完整结论 | R12–R13 |
| 缺少因果和初值条件 | R14–R16 |
| 能力外表达式 | R17 |
| 可证明代数等价与函数定义替换 | R18–R19 |
| 收敛域边界与左右序列歧义 | R20–R21 |
| 采样点巧合不能证明恒等 | R22–R23 |
| 显式非零初值 | R24 |

R03–R05 的输入是测试数据，绝不能作为 Python 代码执行。解析器必须先进行 token / AST 白名单校验。执行器遇到超时、资源限制或解析异常，应返回可解释的未知状态，不应使桌面应用崩溃。

## 证据等级与统计要求

- `correct` 需要规则重写或符号恒等的证据；“若干采样点相同”只能作为辅助证据。
- `wrong` 需要规则结果不符、条件矛盾、ROC 冲突或合法定义域中的可靠反例。
- `unknown` 表示解析拒绝、能力不足或证明前提不足，不能把它统计为正确推导。
- `incomplete` 用于表达式正确但必要 ROC 未提供。
- 引擎运行结果应报告总数、通过数、失败数、预期与实际状态、预期与实际首错行。不得只展示精度百分比而隐藏失败。
- 完成 100 条验收集只说明本固定数据集通过，不能据此宣称任意信号表达式都可正确处理。
- 本文是测试设计，不代表测试已经执行或通过；实际结果以测试运行报告为准。
